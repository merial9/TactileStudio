    FIELD GUIDE & DOCUMENTATION

    Getting started

    Tactile is a pixel-art studio that runs in your browser. Everything you draw lives on a pixel grid, in layers and frames, and is saved automatically to this browser.

    The workspace

    • Tool strip icons: each tool has its own shape. The Marquee button shows the selection type you used last (dashed rectangle, dashed ellipse or lasso loop, always with a small arrow), and the More Shapes button shows an ellipse or a polygon. The solid rectangle is the Rectangle tool, the halftone dots are Dither, the diamond with a dashed outline is Contour Stroke, and two circles with arrows are Replace Color.
    • Menu bar (top): File, Select, Edit, Sprite, Layer, Frame, View, Help. Every menu item is also a command with its own shortcut.
    • Project tabs: each open sprite is a tab. A dot on a tab means unsaved changes. Use + to start another sprite.
    • Options bar: settings for the active tool (stroke size, shape, opacity, ink, fill, symmetry, zoom).
    • Left panel: palette, color mixer, foreground / background colors and quick effects.
    • Tool strip (right of the canvas): all drawing and selection tools.
    • Canvas: the sprite. Badges in the corner show the current tool and position.
    • Timeline (bottom): layers on the left, frames across the top, transport and onion-skin controls above.
    • Status bar: foreground color, canvas size, current tool, autosave time, frame and zoom.
    • Floating preview: a small live window showing the sprite at actual size or animating. Toggle it with F7.

    Your first sprite in 60 seconds

    1. Press Ctrl+Alt+N, choose a size (for example 32 × 32) and confirm.
    2. Pick a color in the palette, press B for the Pencil and draw. Right-click draws with the background color.
    3. Press Ctrl+Z to undo anything.
    4. Add a layer with + LAYER to keep outlines and shading separate.
    5. Save with Ctrl+S (.ora project) or export a PNG from File → Export…

    Projects & files

    Creating a sprite

    File → New Sprite… sets a name and size. Any size from 1 px up to 16,384 px per side is allowed (the browser's own canvas ceiling). Presets give quick square sizes. You can change an existing sprite from the Sprite menu: Sprite Size… (Ctrl+Alt+I) scales the artwork with nearest-neighbour resampling, with optional percent and a keep-proportions switch; Canvas Size… (Ctrl+Alt+C) adds or removes space around the artwork and lets you pin it to any of nine anchor positions; Trim Canvas crops the canvas to the area actually used by every frame and layer, so animations stay aligned. All three can be undone.

    Opening sprites and images

    Use File → Open… (Ctrl+O), drag files onto the window, or paste an image. Supported: PNG, JPG, GIF, WebP, BMP, SVG, OpenRaster (.ora), Aseprite / LibreSprite (.ase, .aseprite), legacy .json projects, and palette files (.gpl, .hex, .act).

    When you open one or more plain images, a dialog groups the choices by what you want to do:

    • New sprite → Separate sprites: every image becomes its own tab at its exact pixel size.
    • New sprite → One animated sprite: files like walk_00.png, walk_01.png… become the ordered frames of one sprite. If a file looks like part of a numbered sequence, a shortcut offers to load the whole sequence from its folder.
    • New sprite → Slice a sprite sheet (also File → Import Sprite Sheet…): cut an image into frames by frame size or by columns and rows, with margin and spacing, optional skipping of empty cells and row-wise or column-wise reading. The preview shows the grid and numbers the frames; the result is a new sprite or extra frames in the current one.
    • Add to the current sprite → As new frames: images are appended as frames of the open sprite.
    • Add to the current sprite → As a new layer: the image is added as a layer in the current frame. It is centered and never upscaled.
    • Colors → Use as color palette: the unique colors of the first image become the palette.

    Pasting from the clipboard

    Copy any image in another program (or a browser, or a screenshot) and press Ctrl+V in Tactile. The image's size is detected and it opens as a new sprite named Pasted_N at exactly that resolution. If you copied a selection inside Tactile most recently, Ctrl+V pastes that selection into the current layer instead.

    Saving

    • Save (Ctrl+S) writes the project in its current file format (.ora, .png, .gif, .webp or .jpg) to the file it was opened from or last saved to. A new sprite, or one opened from a format Tactile cannot write (.ase, .json, .bmp, .svg), is saved as .ora.
    • Overwrite check: before replacing an existing file, Tactile asks to confirm (Overwrite, Save As… or Cancel). Once that file has been saved more than 2 times in the session the question is skipped. The count belongs to the project: closing it or starting a new sprite resets it, and saving to a different file starts a new count.
    • Save As… (Ctrl+Shift+S) always opens the file dialog, in the folder the file was originally opened from. The dialog itself asks before replacing a file, and the sprite takes the saved file's name.
    • Layers and formats: .ora keeps layers, frames, frame rate and color mode. PNG, JPG, GIF and WebP cannot store layers, and PNG and JPG hold a single frame. Saving a multi-layer or animated project in one of them shows a warning that recommends .ora, with the choice to save flattened anyway or cancel.
    • Browsers without file-system access (Firefox, Safari) cannot overwrite files in place: Save downloads a copy instead. The desktop app (.exe) has no such limit: it uses real file paths and the Windows file dialogs, overwrites files in place, writes through a temporary file so a failed save never corrupts the original, opens .ora / .ase / image files you double-click in Explorer, and restarts itself when you change the hardware-acceleration setting.
    • Autosave keeps a recovery copy in this browser (Preferences → Autosave). It is not a replacement for saving a file; clearing browser data removes it.
    • A dot on a tab means that sprite has unsaved changes.

    Exiting safely

    File → Exit… lists every sprite with unsaved changes and offers Save all & exit, Discard changes or Cancel. When you close a browser tab directly, the browser shows its own generic "leave site?" warning instead, because web pages are not allowed to customise that dialog.

    Drawing tools

    Left click paints with the foreground color, right click with the background color. [ and ] change brush size. While a selection exists, drawing only affects pixels inside it.

    ToolKeyWhat it does and how to use it
    PencilBFreehand pixels. Stroke size, opacity and brush are in the options bar. Shift+click draws a straight line from where the last stroke ended, on one of 8 angles.
    EraserERemoves pixels to transparency. Respects the active selection and locked layers.
    EyedropperI or hold AltClick a pixel to make its color the foreground. Holding Alt switches to it temporarily from any tool.
    Paint BucketG / FFills the connected area of matching color under the cursor with the foreground color.
    LineLClick-drag from start to end for a straight pixel line.
    RectangleUDrag a rectangle. Use the options bar to choose outline, filled, or both.
    EllipseShift+UDrag an ellipse with the same fill / stroke options.
    PolygonPClick to place corners; press Enter to finish and fill, Esc to cancel.
    Contour StrokeCDraws a contour (outline) stroke; see its settings in the options bar.
    Dither / ShadingDPaints a dither pattern for gradients and texture; check the Type and Ink options in the options bar.
    BlurOSoftens the colors under the brush. Best used lightly on larger sprites.
    Replace ColorROpens a live panel (also Edit → Replace Color…): click a pixel to choose the color to find, pick the replacement, choose the area (layer, frame or all frames) and watch the result on the canvas before confirming. See Replace Color below.

    Replace Color

    The panel does not block the canvas. 1 Find: click a pixel on the canvas (or a color in the palette) to choose the color to replace. 2 Replace with: pick any color, or Erase to make the pixels transparent. 3 Where: Layer, Frame or All frames; Similarity also catches nearby shades (RGB sprites only). The changed pixels are shown live on the canvas and in the floating preview window, which is brought to the front; hold Hold: Original to compare. Nothing is written until you press Replace (one undo step); Cancel or Esc leaves the sprite untouched. Turn on Show the colors present in this area to list every color found in the chosen area, most used first, with pixel counts on hover; the option is remembered. Drag the panel by its title to move it.

    Fixed angles with Shift

    Holding Shift locks the angle to 8 directions (every 45°): lines and polygon segments snap to horizontal, vertical or diagonal; the Move tool and dragging a selection slide along those directions; rotating a selection turns in 45° steps. Rectangles and ellipses become perfect squares and circles.

    Brushes

    Edit → Brushes… (Ctrl+Alt+B) opens the brush manager, also reachable from the … button next to the Brush list in the options bar. Presets are square, circle, diamond, plus, horizontal and vertical lines, and the two diagonals. Create your own with + From selection · Shape (the selection's shape, painted in the foreground color), + From selection · Colors (a stamp that keeps its colors) or + Paint a new brush (a small pixel editor, up to 32 × 32). Custom brushes are saved in this browser. The stroke size scales a custom brush in whole-pixel steps. Brushes apply to the Pencil and Eraser.

    Symmetry

    Edit → Symmetry opens a side menu: vertical mirror, horizontal mirror, off, and show or hide the guide lines. While a mirror is active the options bar shows a reminder.

    Tips

    • Draw outlines and fills on separate layers so you can recolor without redrawing.
    • Use the pixel grid (View → Toggle Pixel Grid) while zoomed in to place single pixels accurately.
    • Preferences has a pixel-perfect drawing option and a crosshair style for the cursor.

    Selections & transforms

    Making a selection

    • M rectangular marquee, Shift+M elliptical marquee, Q freehand lasso.
    • Ctrl+A selects everything, Ctrl+D deselects, Ctrl+Shift+I inverts.
    • Combine: hold Shift while dragging to add, Alt to subtract, Shift+Alt to keep only the intersection.
    • Shape: hold Shift while dragging for a perfect square (or circle), Ctrl to grow the box outward from the point you clicked.
    • Double-click selects the whole grid cell under the pointer (cell size = grid step); right-click removes the selection.
    • Ctrl+click a layer to select exactly the pixels it contains.

    Working with a selection

    • Move: drag inside the selection, or use the Move tool (V). With nothing selected, Move drags the whole layer.
    • Resize: drag an edge or corner handle to scale the selected pixels; Shift keeps the proportions, Ctrl scales from the center, and dragging past the opposite edge flips the content.
    • Rotate: drag the round handle above the selection; hold Shift for 15° steps.
    • Flip: Shift+H horizontal, Shift+V vertical (whole layer when nothing is selected).
    • Cut / Copy / Paste: Ctrl+X / C / V. After a cut or paste the pixels float and can still be dragged until you click elsewhere.
    • Clear: Delete or Backspace erases the selected pixels.
    • Crop to Selection (Select or Sprite menu) resizes the sprite to the selected area.

    Colors & palettes

    Foreground and background

    The two color slots at the bottom of the left panel hold the colors used by left and right click. X swaps them. Click a swatch in the palette to set the foreground; Alt+scroll cycles through palette colors.

    Color mixer

    The mixer tabs let you build a color with a wheel, sliders or a hex code, and set its alpha (transparency).

    Palettes

    • Choose a built-in palette from the quick palette list in the left panel. Whenever the foreground color changes (palette click, eyedropper, mixer, swap, undo of a color pick…) a long palette glides so the selected swatch sits in the middle of the list, keeping its neighbouring shades in view. This can be turned off in Preferences (Auto-scroll the palette to the selected color).
    • Import your own with File → Import Palette…; it then appears by its file name under "Imported palettes" in the palette dropdown, so you can switch back to it later (.gpl, .hex, .act) or from an image's colors. Palettes hold up to 256 colors.

    Color modes (Sprite → Color Mode)

    • RGB: full color, unlimited colors.
    • Indexed: every pixel snaps to the nearest palette color.
    • Indexed + Dither: snaps to the palette using an ordered dither pattern to simulate in-between shades.

    Effects

    Quick effects in the left panel work on the current layer: Sharpen, Blur, Despeckle (removes stray single pixels) and three outlines in the foreground color. Outline ▢ is the original square outline (touches diagonal neighbours); Outline ✚ uses only the four orthogonal neighbours, so corners stay rounded instead of pointed; Inner ✚ draws the cross outline on the shape's own edge pixels instead of outside it.

    Layers

    Layers stack like transparent sheets. They are listed on the left of the timeline; the top row is the top layer. Every frame has the same layers.

    • + LAYER adds a new layer to the sprite.
    • Click a layer to make it active. Up / Down move the active layer; with Shift they extend a multi-layer selection.
    • Eye shows or hides the layer in every frame. Lock prevents edits to it.
    • Opacity slider sets how see-through the layer is.
    • ▲ ▼ reorder; ✕ deletes the layer.
    • Double-click the name to rename (or press F2 / Layer → Rename Layer…).
    • Shift+click selects a range; Ctrl+Shift+click adds or removes a single layer.

    Timeline & animation

    Frames

    • + FRAME adds a blank frame, DUP duplicates the current one, DEL removes it.
    • Click a frame number to jump to it. Left / Right step between frames; with Shift they extend the selection. Shift+click selects a range, Ctrl+click adds or removes one.
    • The dot in a cel shows that the layer has content on that frame.

    Playback

    • Transport buttons: play, stop, first / previous / next / last frame.
    • LOOP repeats the animation. The FPS slider sets playback speed (1 to 60).
    • Open the floating preview (F7) to watch the animation at actual size while you keep drawing.

    Onion skin

    ONION shows the neighbouring frame as a faint ghost so you can line up motion. The slider next to it sets the ghost's strength.

    Timeline panel

    Press Tab (or the TAB button) to hide or show the timeline. Drag the dividers to resize the timeline and its columns.

    View & navigation

    • Zoom: scroll wheel, the Zoom tool (Z, Shift-click to zoom out), the zoom box in the status bar, or View → Zoom In / Out. Zoom steps are whole multiples so pixels stay crisp; the status bar shows the allowed range.
    • Pan: hold Space and drag, use the Hand tool (H), or drag with the middle mouse button.
    • Center: Home re-centers the canvas.
    • Pixel grid: View → Toggle Pixel Grid. Grid step, thickness, opacity and snapping are in Preferences.
    • Transparency checkerboard colors can be changed in Preferences.
    • Very large sprites open at 100% and can be scrolled; drawing and tools work the same.

    Exporting

    File → Export… opens the export dialog. Choose what to export, how to arrange it, and where to put it.

    Options

    • Format: PNG (still), GIF or WebP (still or animated). PNG cannot be animated. WebP has a quality setting.
    • Layout: Separate files (one image per frame, with a base name, start number and zero padding), Sprite sheet (all frames in one image: horizontal strip, vertical strip, or grid with a column count and gap) or Animation (one GIF / WebP).
    • Frames: all frames, or the selected / typed range (for example 1-4, 7).
    • Layers: visible layers merged, the selected layers, or one specific layer.
    • Scale: percentage with no upper limit. Whole multiples only keeps every pixel the same size (100, 200, 300…). The only restriction is the browser: the result must fit in a canvas of 16,384 px per side.
    • Destination: a folder you pick, or a single ZIP, when exporting several files.

    The dialog shows a preview of the file names before you export.

    Settings & customisation

    • Color theme and Highlight color (Preferences → Workspace): pick a theme, then any accent color for selections, active tools and readouts. The reset button returns to the theme's own accent.
    • Keyboard shortcuts: Edit → Keyboard Shortcuts… lets you reassign every command. Conflicts are reported and moved for you.
    • Hardware acceleration (Preferences): Auto keeps the defaults, On asks the browser to back canvases with the GPU (smoother zoom and drawing on big sprites), Off forces software canvases (faster fills and effects, and a fallback for display glitches). Changing it needs a reload; sprites are autosaved first. The browser can still override the request, and its own graphics-acceleration setting must be on.
    • Preferences: grid, crosshair style, symmetry guides, pixel-perfect drawing, wheel-zoom behaviour, undo history length, autosave, export scale and the floating preview.
    • Panels: the floating preview and timeline can be resized by dragging their edges.

    Mouse

    Troubleshooting & limits

    Performance with big sprites

    High zoom on a large sprite (for example 900% on 300 × 300 px or more) used to drop to a few frames per second because the selection, symmetry and shape-preview layers were allocated at full screen size, cleared on every repaint and blended over the canvas even when empty. They are now allocated within a fixed pixel budget, hidden while empty, and the symmetry guides are only repainted when they change; the marching ants pause while the tab is hidden. If a very large sprite still feels slow: hide the pixel grid (View), switch symmetry guides off, try Preferences → Hardware acceleration (On usually helps zoom and pan, Off helps fills and effects), or zoom out a step. Selection outlines may look slightly thicker at extreme zoom, because those layers use fewer pixels than the screen.

    Limits

    • Canvas size: 1 px to 16,384 px per side (browser limit). Very large canvases use a lot of memory; if the page becomes slow, work at a smaller size.
    • Palettes: up to 256 colors. Export scale and sprite-sheet size are limited only by the same browser canvas ceiling.

    Common questions

    • An image will not import. The error names the file and says whether it is empty, damaged or unsupported. Files held in cloud folders must be available offline first.
    • Pasting does nothing. Click on the canvas first (not in a text box), make sure no dialog is open, and that the clipboard really holds an image.
    • The tool seems stuck on the eyedropper. Holding Alt switches to the eyedropper temporarily. It now releases itself on key-up, when the window loses focus, or as soon as the pointer or a key shows Alt is no longer held. Picking any tool directly also works.
    • I cannot draw. Check the layer is not locked or hidden, and that no selection excludes the area you are painting.
    • The canvas flickers or feels slow. Try Preferences → Hardware acceleration: switch between On and Off and reload, and check that your browser's graphics acceleration is enabled.
    • My work disappeared after clearing the browser. Autosave lives in browser storage. Save .ora files for anything important.
    • The browser warns before closing. A sprite has unsaved changes. Use File → Exit… for the save-all / discard / cancel dialog.
