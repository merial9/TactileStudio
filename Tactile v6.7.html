FIELD GUIDE & SHORTCUTS

TOOLS & SHORTCUTS

Defaults are listed here. Change them in Edit → Keyboard Shortcuts…

  • B — Pencil Tool
  • E — Eraser Tool
  • G / F — Paint Bucket (Flood Fill)
  • I / Hold Alt — Eyedropper (Sample color)
  • M / Shift+M — Rectangular / Ellipse Marquee
  • Q — Lasso Selection
  • V — Move Tool (selection or whole layer)
  • O — Blur Tool
  • L — Straight Line Tool
  • U / Shift+U — Rectangle / Ellipse Shape
  • D — Dither / Shading Tool
  • C / P — Contour Stroke / Polygon (Enter fills)
  • Shift+H / Shift+V — Flip selection (or whole layer) horizontally / vertically
  • ? / Ctrl+Alt+N / Ctrl+S / , — Help / New project / Save / Settings
  • H / Space+Drag — Hand Pan Canvas
  • Z — Zoom Tool
  • X — Swap Foreground & Background Colors
  • R — Replace Color
  • [ / ] — Decrease / Increase Brush Size
  • Tab — Toggle Timeline Panel
  • F7 / Preview Btn — Toggle Floating Preview

MOUSE & ADVANCED CONTROLS

  • Left Click — Draw with Foreground Color
  • Right Click — Draw with Background Color
  • Scroll Wheel — Zoom in to individual pixels
  • Middle Click / Space+Drag — Pan across canvas
  • Alt + Scroll Wheel — Cycle through palette colors
  • Ctrl + Z / Ctrl + Y — Undo / Redo
  • Ctrl + A / Ctrl + D — Select All / Deselect
  • Ctrl + Shift + I — Invert Selection
  • Shift + Drag — Add to selection
  • Alt + Shift / Right-click + Drag — Subtract from selection
  • Ctrl + Shift + Drag — Intersect with selection
  • Ctrl + Click layer — Select layer content
  • Ctrl + C / X / V — Copy / Cut / Paste selection (paste lands at the selection corner)
  • Delete / Backspace — Erase selected pixels
  • Click outside the canvas twice — Deselect
  • Eye icon — Hides / shows that layer in every frame
  • Drag inside a selection — Move its pixels (after Ctrl+X the cut pixels float and can be dragged)
  • Round handle above a selection — Drag to rotate it (hold Shift for 15° steps)
  • While a selection exists, drawing only affects pixels inside it
  • Symmetry Guides — Mirror drawing across X/Y axes!
  • Drag & Drop — Drop images or .ora / .ase / legacy .json project files directly onto the browser!
  • Left / Right — Previous / next frame (Shift extends the frame selection)
  • Up / Down — Select the layer above / below (Shift extends the layer selection)
  • Shift+click a frame number or layer — select a range; Ctrl+click a frame number / Ctrl+Shift+click a layer — add or remove
  • Home — Re-center the canvas; the canvas can be dragged freely with Space / Hand / middle mouse / empty area
  • Double-click a layer name — Rename it
  • Preview / Monitor edges — Drag to resize horizontally and vertically
